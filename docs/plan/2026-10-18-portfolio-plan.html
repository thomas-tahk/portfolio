Decide before anything starts (3 things):
  1. Repo rename: thomas-tahk-portfolio-game → portfolio. GitHub issues get created only after you confirm the final name.
  2. Preview host: decided: GitHub Pages. One deploy publishes main at /portfolio/ and the current milestone branch at /portfolio/preview/. Nothing for you to set up, no other service.
  3. Who runs the agents: decided: cloud routines, medium effort. To keep cost down, it's one cloud session per milestone working through that milestone's issues in order, not one session per issue. Cloud runs have no gh and may not reach outside sites, so every check (including the preview URL check) runs in GitHub Actions and the agent reads the result.

Parts 1–2: settled

  • Structure: plain page at /, game at /play/, one content.json for both, live GitHub feed in the browser, static, no backend.
  • Honesty rules: "AI-assisted" stated plainly. kb-helper described as a proposal nobody adopted. Shows4Us and Amugonna kept in content.json with hidden: true.
  • Headline: you passed on picking one. My call, logged as a taste note: "Tier 1 IT support by day. I build software on my own time." It's plain and true, and it still sells the IT-person-who-builds angle. The variants can try others.
  • Featured 4: knowflow (live) · pocket-draft (live, if the rebuild renders) · priority-post (code + writeup; the app needs a login) · Dormant (moved up because it has no backend and never breaks).
  • Smaller list: kb-helper, plotplan, ServiceNow team workspace (screenshots).

Part 3: how agents work

RuleWhat it means
BranchesOne branch per milestone, m1-…. Each issue gets its own short branch → PR into the milestone branch.
MergingThe agent merges its own PR into the milestone branch once every check passes. No approval from you per issue.
Checks (CI, every PR)Build passes · Playwright: page loads, no horizontal scroll at 375px width, every link returns 2xx (external links retried, so one flaky site doesn't block) · axe accessibility check: zero serious or critical violations · plus the issue's own test.
Taste/wording callsThe agent decides, adds a "Calls I made" list to its PR, and keeps going.
Milestone endThe agent opens one PR from the milestone branch into main. It holds the preview link plus every "Calls I made" note in one list. You open it on your phone and merge or send it back. That's your only review.
StuckIf a check can't pass without a decision only you can make, the agent stops that issue, labels it blocked, and moves on to issues that don't depend on it.
